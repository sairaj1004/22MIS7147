Storyboard — Freelancer–Client Workflow

High-level user flow for the core experience

Scenario

User registers, posts a job, freelancer applies and gets paid

Persona

Client: Lily — new user looking to hire a designer

Step 1: Home / Landing

User opens website and lands on the home page.
Options to Login or Register are visible.
Clear CTAs guide user into workflow.

Step 2: Register / Login



User chooses whether to sign up or login.
Role selection: Client or Freelancer.
Secure form with validation.

Step 3: Client Dashboard


Client dashboard with two main actions:
Post a new project and check project progress.
Helps client manage work efficiently.

Step 4: Project Posting



Client fills form with job details.
Sets budget, deadline, and description.
Posts job to be visible to freelancers.

Step 5: Freelancer Dashboard

Freelancer logs in and sees jobs.
Can filter by category or budget.
Option to apply or view details.

Step 6: Apply / Bidding


Freelancer submits proposal/bid.
Includes cover letter and cost estimate.
Client receives notification of new bid.

Step 7: Project Progress

Overall Progress
✅ Milestone 1: Requirement Gathering
⏳ Milestone 2: Design Phase
⬜ Milestone 3: Final Delivery
Tasks
12/20
Deadline
5 Days Left
Client checks progress on a dashboard.
Shows % completion, milestones, tasks and deadlines.
Provides transparency without needing status calls.

Step 8: Contract & Submission

Client accepts freelancer proposal.
Work milestones defined clearly.
Freelancer uploads completed work.

Step 9: Payment & Rating


⭐⭐⭐⭐⭐
Client makes secure payment.
Both client and freelancer leave ratings.
Workflow ends with confirmation.
